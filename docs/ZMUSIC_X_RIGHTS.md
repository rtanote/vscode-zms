## 3. 現状の設計 (打診不要判明前の設計、当面継続)

初回起動時に QuickPick:

1. GitHub からダウンロード (toyoshim/z-music.js リポジトリの ZMUSIC208.X)
2. ローカルファイルを指定

ダウンロード時: SHA-256 検証 + 著作権通知
([src/player/DriverManager.ts](../src/player/DriverManager.ts) の `notifyCopyright()`)。

## 4. VSIX 同梱への切替検討 (将来的なオプション)

**Pros**:

- 初回起動の QuickPick / ダウンロードステップが不要になり UX 大幅改善
- toyoshim 氏リポの URL 生存性に依存しなくなる
- Marketplace の初回体験が「install → 即再生」となる
- ネットワーク越しダウンロードの失敗シナリオが消える

**Cons**:

- VSIX サイズ +50KB 前後 (ZMUSIC208.X は約 40KB)
- 我々が redistribute 主体となる (許諾はあるので責任軽微)
- ローカル別バージョン利用ユーザ向けに override 設定 (`zmusic.driver.path`) は継続必要

**推奨アクション**:

1. 切替時に `.vscodeignore` から `media/player/ZMUSIC208.X` を除外
2. `DriverManager.ensureDriver()` の優先順を「設定パス → 同梱 → キャッシュ → ダウンロード」に
3. QuickPick は「デフォルト同梱を使う」がトップ選択肢に
